# Stitch Design Prompt - DevWebCamp

Prompt maestro para generar el diseño de la aplicación en Stitch, respetando la estructura de la plataforma y el estilo corporativo/B2B en Light Mode.

---

## 📋 Prompt para Stitch

```text
Design a comprehensive, high-end web application for "DevWebCamp", an enterprise-grade multi-day tech conference platform for engineering leaders, CTOs, and B2B tech innovators.

### Aesthetic & Visual Tone:
- Atmosphere: Prestigious, sober, corporate, and cutting-edge tech conference. 
- Theme: Pristine, modern Light Mode with clean off-white canvas backgrounds, high typography contrast, and generous whitespace.
- UI Style: Refined glassmorphism and subtle soft glow accents. Translucent frosted-glass cards (backdrop-filter blur), ultra-thin delicate borders, polished rounded corners, and soft multi-layered shadows.
- Color Palette: Automatic enterprise B2B corporate palette chosen by the model (conveying trust, technology leadership, and clarity) with crisp neutral surfaces and refined functional accents for status, actions, and tags. Do NOT use harsh neon tones.

---

### Core Screens & Layout Structure to Generate:

1. Public Conference Landing Page:
   - Header & Navigation: Sleek sticky glass navbar with logo, nav links (Agenda, Speakers, Passes, Venue), and action buttons ("Get Ticket" & "Sign In").
   - Hero Section: High-impact conference introduction with interactive live countdown timer, event dates, physical/virtual location indicators, and executive value proposition.
   - Speakers Grid: Premium speaker directory showcasing professional headshots, titles/affiliations (e.g. CTO, VP of Eng), topic specialty tags, and professional network links.
   - Interactive Agenda & Schedule: Multi-day toggle tabs (Friday / Saturday), category badges (Keynotes, Technical Workshops, Executive Panels), time blocks with live status indicators, and speaker avatar previews.
   - Ticket Pricing & Passes Comparison: Clear 3-tier comparison matrix:
     * In-Person Pass (Full access, workshops, credential, physical commemorative gift).
     * Virtual Pass (Full HD streaming & virtual workshop access).
     * Free Pass (Curated access to streaming keynotes).

2. Attendee Dashboard & Digital Ticket:
   - Digital Conference Badge: Interactive event pass card featuring attendee name, role, ticket tier badge, unique hex validation token, and a crisp scannable QR code. Include a "Printable Badge / Add to Apple Wallet" trigger.
   - Workshop Registration Hub: Interactive schedule builder allowing in-person ticket holders to reserve workshop slots with real-time seat availability and capacity progress bars.

3. Purchase & Swag Selection Checkout:
   - Streamlined 2-step checkout flow.
   - Gift / Swag selector for in-person attendees with visual picker for commemorative gifts (apparel with size selector, executive pins, curated tech kit).
   - Order summary with secure payment methods.

4. Executive Admin Backoffice:
   - Analytics Overview: Metric summary cards displaying total revenue, registered attendees breakdown by tier, and gift inventory demand stats.
   - Management Tables: Clean data tables for managing speakers and scheduling conference slots with capacity limit controls.

Design all views with responsive layouts, accessible typography hierarchy, and polished Radix-inspired micro-interactions.
```
